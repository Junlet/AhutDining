# 菜品数据格式与替换方法

## 0. 当前数据来源（2026-11 导入真实数据）

* 原始文件：`data/source/食堂菜品价格.xlsx`（来自 PocketAHUT `/canteen/dishes`，已 gitignore）
* 规模：2 个校区 / 13 个食堂楼层 / 164 个窗口 / 2,603 道菜；价格与分类为原始数据
* 营养成分：Excel 未提供，由 `tools/import_from_xlsx.py` 估算（分类基准 + 菜名关键词），
  每道菜 `note` 里标注「营养值按分类与菜名估算」
* 派生文件：`data/dishes_real.csv`（可编辑后重新导入，已入库便于复现）

导入流程：

```bash
python tools/import_from_xlsx.py "data/source/食堂菜品价格.xlsx" --apply
# 或先导出 CSV 手工修正营养值再导入
python tools/import_dishes.py --export data/dishes_real.csv
python tools/import_from_xlsx.py "data/source/食堂菜品价格.xlsx"   # 重新生成 CSV（会覆盖手工修改，注意备份）
python tools/import_dishes.py --file data/dishes_real.csv --replace
```

估算规则在 `tools/import_from_xlsx.py`：`CATEGORY_BASE`（分类基准）与
食材（牛肉/鸡/鱼/蛋/豆制品…）、做法（炸/煎/红烧/清蒸…）、份量（大份/小份）关键词。
拿到官方营养数据后，直接改 CSV 的 `protein/fat/carbs/kcal` 四列再导入即可。
## 1. 数据是怎么放的

| 层 | 表 | 说明 |
|----|----|------|
| 校区/食堂 | `canteens(campus, name)` | 目前：本部（第一食堂、第二食堂、民族餐厅）、东区（秀山一食堂、秀山二食堂） |
| 窗口 | `windows(canteen_id, name, floor, open_hours)` | 16 个窗口，如「家常小炒」「麻辣烫（自助）」「面点档」 |
| 菜品 | `dishes(...)` | 61 道示例菜，含价格、单位、热量、蛋白/脂肪/碳水、是否主食/含蔬菜/自助、标签、备注 |

数据库文件：`data/dining.db`（首次启动自动创建，已加入 `.gitignore`）。

## 2. CSV 列说明

`data/dishes_sample.csv` 就是当前示例库的导出，可直接当模板改。

| 列 | 含义 | 示例 |
|----|------|------|
| `campus` | 校区 | 本部 / 东区 |
| `canteen` | 食堂名 | 第一食堂 |
| `window` | 窗口名 | 家常小炒 |
| `floor` | 楼层（可空） | 1F |
| `open_hours` | 营业时段（可空） | `10:30-13:30,16:30-19:30` |
| `name` | 菜名 | 宫保鸡丁 |
| `category` | 分类：早餐/荤菜/素菜/主食/汤/饮品/水果/小吃/套餐/自助 | 荤菜 |
| `price` | 单价（元） | 10 |
| `unit` | 计量单位 | 份 |
| `kcal` | 热量（kcal），**留空则按 4P+9F+4C 自动算** | 260 |
| `protein` | 蛋白质（g/份） | 20 |
| `fat` | 脂肪（g/份） | 14 |
| `carbs` | 碳水化合物（g/份） | 12 |
| `is_staple` | 是否主食（推荐时不会重复叠加） | 0/1 |
| `is_vegetable` | 是否含蔬菜 | 0/1 |
| `is_self_service` | 是否自助/自选（会提示按实际取餐量折算） | 0/1 |
| `tags` | 标签，逗号分隔（搜索匹配） | `微辣,下饭` |
| `note` | 备注 | 脂肪偏高 |

## 3. 导入 / 导出

```bash
# 导出当前库（拿模板）
python tools/import_dishes.py --export data/dishes.csv

# 校验一行都不改地导入会怎样
python tools/import_dishes.py --file data/dishes.csv --dry-run

# 导入：同名同窗口视为更新，其余新增
python tools/import_dishes.py --file data/dishes.csv

# 整体替换（会清空现有菜品，收藏/评论按菜品 id 关联，建议替换后重建）
python tools/import_dishes.py --file 真实菜单.csv --replace
```

导入不会动用户数据（资料、记录、图片）；只有 `--replace` 会清空菜品。

## 4. 换成真实安工大菜单的建议流程

1. 先 `--export data/dishes.csv` 拿到模板与分类规范；
2. 用 Excel/WPS 填真实数据，**先只填菜名、食堂、窗口、价格**，营养素可先留空（会算成 0，推荐会提示缺数据）；
3. 分窗口查营养值：食堂没有公布营养素时，可用《中国食物成分表》按"食材 + 常见用油"估算，
   例如"一两米饭 ≈ 蛋白 4.4g / 脂肪 0.6g / 碳水 51g"（示例库即按此口径）；
4. 填完后 `--dry-run` 校验，再 `--file` 导入，打开首页即生效。

## 5. 数据来源与免责

* 结构参考 `PocketAHUT` 文档的食堂模块（本部/东区、窗口维度、比价、窗口评分）；
* 数值为**示例估算**，用于跑通系统，不代表食堂官方营养成分；
* 若食堂公布真实数据，请以官方为准并覆盖本文件与数据库。
